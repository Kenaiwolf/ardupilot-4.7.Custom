========================================================================
VECTORED-THRUST ROVER — TUNING & TROUBLESHOOTING GUIDE
branch rover-4.7-custom, allocator = MOT_VEC_FOSSEN=1
========================================================================
VSTUPY: len Mission Planner (Config -> Full Parameter List), zive
hodnoty v MP (labely: yawrate, ch1out=servo, ch3out=throttle) a
pozorovanie lodi ocami. Ziadne logy, ziaden iny software.

========================================================================
SEKCIA 0 — PREDPOKLADY (skontrolovat v Full Parameter List pred vodou)
========================================================================

[KROK] P0.1/SETUP/kontrola pevnych parametrov
CO:    Overit v Config -> Full Parameter List:
       MOT_VEC_FOSSEN = 1, MOT_VEC_ANGLEMAX = 90,
       ATC_STR_ACC_MAX = 45, ATC_STR_DEC_MAX = 45,
       MOT_SLEWRATE = 100, MOT_REV_DELAY = 0
AKO:   Vyhladat kazde meno, porovnat hodnotu, zapisat ak sa lisi.
LIMIT: Ak ANGLEMAX nie je 90 -> nastav 90 (inak sa rozbije fold/coast).
       Ak ACC/DEC_MAX je 0.12 -> nastav 45 (legacy default lomi rampu).
       Ak REV_DELAY > 0 -> nastav 0 (neinicializovany stav v kode,
       audit F11 — reverzny delay nepouzivame).
ROZHOD: Vsetko sedi -> FAZA A. Nieco sa lisi -> zapis a pokracuj.

[KROK] P0.2/SETUP/MOT_VEC_TRN_MS rozsah
CO:    Skontrolovat MOT_VEC_TRN_MS je v rozsahu 0-3000.
AKO:   Full Parameter List -> MOT_VEC_TRN_MS.
LIMIT: Ak hodnota > 3000 alebo < 0 -> nastav 800 a pokracuj.
       (Kod hodnotu neorezava — audit F4; >3000 ms = desiatky sekund
       mrtveho plynu po kazdom pivote.)

[KROK] P0.3/SETUP/ATC_STR_RAT_MAX strop
CO:    Nastavit ATC_STR_RAT_MAX = maximalny otacaci rate, ktory chces
       povolit [deg/s].
AKO:   Full Parameter List -> ATC_STR_RAT_MAX. Zacni 90 deg/s.
LIMIT: Meranie: Acro, plna paka — ak loď nevysraje viac nez ~60 deg/s,
       strop nad 90 nema efekt; drz 90.
ROZHOD: Zapisane -> FAZA A.

[KROK] P0.4/SETUP/ATC_TURN_MAX_G a SMAX
CO:    ATC_TURN_MAX_G nechat default, ATC_STR_RAT_SMAX nechat default.
AKO:   Nemas na vode ako kalibrovat G-limit; SMAX ladi len oscillacia
       (krok B5). Zatial bez zasahu.
ROZHOD: -> FAZA A.

[KROK] P0.5/SETUP/MOT_VEC_DEADBAND nesmie byt 0
CO:    Skontrolovat MOT_VEC_DEADBAND > 0 (default 0.03).
AKO:   Full Parameter List. Ak 0 -> nastav 0.03.
LIMIT: Pri 0 sa vypina aj latch-guard brake — jeden sumovy tick moze
       zaseknut brzdu (audit: deadband drzi guard). Nikdy nenastavuj 0.
ROZHOD: -> FAZA A.

[KROK] P0.6/SETUP/zive labely v MP
CO:    Otvorit v MP tuning graf a zvolit: yawrate (gyro rotacia),
       ch1out (servo vystup), ch3out (throttle vystup).
AKO:   Data screen -> Tuning -> zaskrtnut tieto tri polia.
LIMIT: Ziadne ine labely sa v krokoch nepouzivaju.

========================================================================
PORADIE — povinne A->B->C->D->E
========================================================================
A: priama plavba (surge) — bez nej sa neda merat nic dalsie.
B: pivot krivka + brzda — staticke otacanie, nezavisle od A.
C: prechodove vrstvy (deadband/blend/coast) — len doladovanie.
D: drift kompenzacia — az po A-C naladenych.
E: loiter/vodne scenare — integracia.
Pravidlo: symptóm v nizsej faze sa neriesi, kym vyssia faza nie je
zelena. Zle naladena pivot krivka sa tvári ako pokazena brzda.

FAZA A2 — speed accel/decel krivky (surge dynamika)
------------------------------------------------------------------------
[KROK] A2.1/ATC_ACC_VEQ rovnovazna rychlost
CO:    Nastavit na nameranu maximalnu rychlost pri plnom plyne.
AKO:   Manual, plny plyn z pokoja, casom rychlost dobehne na plateau
       (~25 s). Plateau hodnota = ACC_VEQ.
LIMIT: Musi byt > CRUISE_SPEED, inak demand nikdy nedosiahne ciel.
ROZHOD: Zapisane -> A2.2.

[KROK] A2.2/ATC_ACCEL_MAX = a0
CO:    Zrychlenie pri v~0 pri plnom plyne.
AKO:   Z logu: dv/dt v prvej sekunde po plnom plyne. Odhad z ocami:
       0.3 je konzervativne, nedoladovat bez logu.
LIMIT: Prilis vysoke = demand bezi rychlejsie nez lod -> PID saturacia.
ROZHOD: -> A2.3.

[KROK] A2.3/ATC_DEC_V2 coast brzda
CO:    Kvadraticky koeficient plavby narazom.
AKO:   Manual: rozbehni ~1.2 m/s, plyn na 0, meraj cas zastavenia.
       Z krivky: DEC_V2 sa ladi tak, aby Loiter zastavil bez prestrelu
       aj bez nadcenia. Prestrelenie -> DEC_V2 +0.01. Zastavenie prilis
       skoro (lod sa taha) -> -0.01.
LIMIT: Pri 0 sa prepne na legacy konstantu ATC_DECEL_MAX.
ROZHOD: -> A2.4.

[KROK] A2.4/ATC_DEC_BRK reverzna brzda
CO:    Nasobic coast krivky pocas aktivnej brzdy (ATC_BRAKE=1).
AKO:   Loiter z ~1 m/s: lod zastavi vyrazne pred cielom -> DEC_BRK
       prilis nizky (+0.5). Prestreli -> DEC_V2 je chyba, nie BRK.
LIMIT: Rozsah 1-4. Pri 1.0 = reverz nerovnany (nekonzervativne).
ROZHOD: -> FAZA B.

------------------------------------------------------------------------
FAZA B — pivot krivka (Acro, staticke otacanie)
------------------------------------------------------------------------
[KROK] B1/PIVOT/MOT_YAW_CRS_RATE kalibracia
CO:    Zmerat skutocny plateau rate pri plnej pake.
AKO:   Acro, armovane, drz plnu paku jednym smerom > 4 s. Sleduj
       yawrate v MP tuning grafe a GPS otoc v mape. Cas na 360 deg
       stopkami na telefone -> deg/s = 360/cas.
ZAPIS: MOT_YAW_CRS_RATE = namerana hodnota.
LIMIT: Ak loď neudrzi rotaciu > 3 s -> najprv mechanika/motor,
       nie parameter.
ROZHOD: Zapisane -> B2.

[KROK] B2/PIVOT/MOT_YAW_CRS_THR kalibracia
CO:    Zmerat throttle pri rovnakom plateaue.
AKO:   Pri B1 citaj ch3out ustalenu hodnotu [%].
ZAPIS: MOT_YAW_CRS_THR = namerane %.
ROZHOD: Zapisane -> B3.

[KROK] B3/PIVOT/MOT_VEC_YAW_EXP tvar krivky
CO:    Pri STVRTINOVEJ pake (nie plnej) pozoruj rotaciu.
AKO:   Acro, paka ~25 %. Oko: rotacia zretelna < ~2 s od pohybu paky.
ZAPIS: Rotacia prisilna/malo -> EXP zniz o 0.2 smerom k 1.0.
       Servo kmita/jitter pri malej pake -> EXP zvys o 0.2.
LIMIT: Rozsah 1.0-3.0; mimo nej nikdy.
ROZHOD: -> B4.

------------------------------------------------------------------------
FAZA C — rotation brake
------------------------------------------------------------------------
[KROK] C1/BRK/MOT_VEC_BRK dobeh test
CO:    Acro: plna paka jednym smerom 3 s, potom skokovo pustit.
AKO:   Sleduj ocami a yawrate: dobeh rotacie po pusteni.
LIMIT: Ciel: dobeh < ~1 otocka (360 deg) a ZIADNA spatna oscilacia.
ZAPIS: Dobeha dlho -> VEC_BRK +20. Prehoupne spat -> VEC_BRK -20.
       Opakuj do < 1 otocky a ziadnej oscilacie.
ROZHOD: -> C2.

[KROK] C2/BRK_ASYM/reverzna ucinnost
CO:    Ak pri spravnom VEC_BRK brzda stale slaba (reverz slaby).
AKO:   Porovnaj dobeh C1 pred/po; reverzny tah je fyzicky slabsi.
ZAPIS: VEC_BRK_ASYM +0.1 kroky; ak zacne oscilovat -> -0.1.
LIMIT: Nikdy nad 2.0. Prehnanie = oscilacia aj pri dobrom VEC_BRK.
ROZHOD: -> D.

------------------------------------------------------------------------
FAZA D — prechody allocatora
------------------------------------------------------------------------
[KROK] D1/MOT_VEC_DEADBAND — pokojovy sum
CO:    Manual/Acro, motory vypnute/nečinné, strazit ch1out pri
       centrovaných páčkách.
AKO:   Ak servo kmita v pokoji -> DEADBAND +0.01. Ak pri malom dopyte
       je slepa zona (servo nereaguje) -> -0.01.
LIMIT: NIKDY 0 (vypina latch-guard — audit). Horny strop 0.2.
ROZHOD: -> D2.

[KROK] D2/MOT_VEC_BLND_THR — chovanie pri malom plyne
CO:    Acro, pomaly pridavat plyn z 0; sleduj servo (ch1out) pri
       zaciatku pohybu.
AKO:   Servo „nervozne" hadze uhol pri prvom plyne -> +0.05.
       Pri rozbehu pivotu uhol oneskoruje -> -0.05.
LIMIT: Rozsah 0-1. Default 0.15 funguje pre vacsinu pripadov.
ROZHOD: -> D3.

[KROK] D3/MOT_VEC_RESID_TC — kmitanie rezimov
CO:    Prechody plyn 0 -> plny -> 0 v Acro; sleduj ci servo „cucka"
       medzi surge/pivot spravanim.
AKO:   Vidis kmitanie -> RESID_TC +0.2. Inak nechat 0.5.
LIMIT: >1.0 = prilis pomala odozva — nepouzivat.
ROZHOD: -> D4.

[KROK] D4/MOT_VEC_TRN_MS — servo transit cas
CO:    Na brehu (alebo hladkej vode): flip servo -90 -> +90 merat cas
       do dorazu stopkami.
AKO:   Zapis namerany cas [ms] do MOT_VEC_TRN_MS. Rozsah 0-3000.
       0 = vypne supresiu (nedoporucene).
LIMIT: Symptom na vode: mrtvy plyn po zmene smeru pivotu > nastavenej
       hodnoty = param mimo rozsah -> P0.2.
ROZHOD: -> E.

INFORMACNE (neladitelne): fold hysterézia ±2 deg hardcoded;
rotation-brake debounce 3 ticky ~60 ms; transit okno sa restartuje
pri kazdom flipu strany — zamer, nie bug.

------------------------------------------------------------------------
FAZA E — drift kompenzacia (len po A-D zelenych)
------------------------------------------------------------------------
[KROK] E1/DRIFT gains aktivacia
CO:    MOT_DRIFT_G_LOIT = 1.0 a MOT_DRIFT_G_NAV = 1.0 — obidva
       zapinaju kompenzaciu (kill-switch ak = 0).
AKO:   Loiter za vetra/prudu: GPS stopa v MP mape — loď klze z kruhu
       > ~2 m -> gain +0.2. Osciluje okolo bodu/hyperkorekcia -> -0.2.
ROZHOD: -> E2.

[KROK] E2/DRIFT_MAXAGE
CO:    Ako dlho stary odhad plati.
AKO:   Nechat 1800. Len ak testujes pri rychlo sa meniacom vetre
       a loď kompenzuje „stary" vietor -> zniz na 600.
LIMIT: 0 = funkcia mrtva. Nikdy 0 ak ju chces pouzivat.
ROZHOD: -> E3.

[KROK] E3/LOIT_CST_THR + LOIT_I_MIN — ci sa vobec vzorkuje
CO:    Overit ze drift estimator dostava vzorky.
AKO:   Loiter 60 s pri vetre -> potom zmenit DRIFT_G_LOIT na 0 a
       sleduj ci sa stopa zhorsi. Ak zhorsenie: estimator vzorkuje.
       Ak ziaden rozdiel: vzorky nevznikaju -> LOIT_CST_THR zniz
       o 0.5 a/alebo LOIT_I_MIN zniz o 0.01; zopakovat.
ROZHOD: -> E4.

[KROK] E4/LOIT_ROT_ANG + LOIT_ROT_RAT + DRIFT_EST_YR
CO:    Gaty blokujuce vzorky pocas rotacie.
AKO:   Ak loď v loiteri stale mierne rotuje (vietor vlecie) a
       E3 ukazal nevzorkovanie: LOIT_ROT_ANG +5, LOIT_ROT_RAT +10,
       DRIFT_EST_YR +5 (vzdy drz DRIFT_EST_YR < LOIT_ROT_RAT).
ROZHOD: -> E5.

[KROK] E5/LOIT_I_ALPHA + LOIT_I_DISAG — rychlost adaptacie
CO:    Ak sa odhad meni prilis pomaly alebo skace.
AKO:   Pomala konvergencia (> ~30 s na zmenu vetra) -> ALPHA +0.05.
       Odhad skace -> DISAG -0.1.
       Nesuhlas blend 25 % -> 50 % pri trvalej zmene je automaticky.
ROZHOD: -> E6.

[KROK] E6/LOIT_DRF_MIN
CO:    Prah aktivacie kompenzacie.
AKO:   Loiter prekompenzuje pri dokonalom pokoji (GPS sum) -> +0.01.
       Necha default ak bez problemov.

INFORMACNE: LOIT_I_EQERR = deprecated, nenastavovat. Zero-decay
(x0.75/tick) a okna ~8 s/~20 s su konstanty v Rover/mode.h —
na vode nemennitelne. Po EKF resete/GPS glitch pocitaj ~8 s do
novej vzorky.

========================================================================
SEKCIA 3 — SYMPTOM -> AKCIA mapa
========================================================================
Format: co vidis ocami/v MP -> presna akcia.

"Pri plnej pake v Acro sa netoci / toci pomaly"
  -> CRS_RATE/THR nakalibrovane? ak nie -> B1/B2
  -> ATC_STR_RAT_MAX prilis nizky -> P0.3
  -> VEC_YAW_EXP > 2.5? -> zniz na 1.67
  -> ACC_MAX/DEC_MAX < 45 -> P0.1

"Dobeh rotacie > ~1 otocka po pusteni paky"
  -> C1 doladit VEC_BRK +20; pri slabom reverze C2 VEC_BRK_ASYM +0.1
  -> servo nedoraza na 90 deg -> mechanika/PWM range (nie parameter)

"Loď sa po pusteni prehoupne a vrati opacne"
  -> VEC_BRK -20, VEC_BRK_ASYM -0.1
  -> DEC_MAX > 45? -> nastav 45

"Mrtvy plyn ~0.8 s pri flip +pivot/-pivot"
  -> NORMALNE: pivot coast = VEC_TRN_MS. Nepridavat nic.
  -> Ak trva > VEC_TRN_MS nastaveneho -> param > 3000? -> P0.2
  -> Ak sa objavuje mimo pivot -> D1 deadband prilis vysoky -> -0.01

"Servo kmita okolo 180 deg pri dopyte tesne za 90 deg"
  -> fold hysterézia existuje; ak kmita aj tak: RESID_TC +0.2 (D3)
  -> kmitanie pod 88 deg = PID oscilacia -> ATC_STR_RAT_SMAX +0.5

"Loiter/Guided unasa a kompenzacia nezabera"
  -> DRIFT_G_LOIT/NAV = 0? -> E1 nastav 1.0
  -> DRIFT_MAXAGE = 0? -> E2
  -> E3 test vzorkovania -> gatovat CST_THR/I_MIN
  -> loď rotuje pocas loiter -> E4 gaty

"Loiter/Auto prestreli ciel a vracia sa"
  -> DEC_V2 prilis nizky (planovana draha kratsia nez realita) -> +0.01
  -> DEC_MIN = 0 pri DEC_V2>0 -> nastav 0.02
  -> ACC_VEQ < CRUISE_SPEED? -> oprav na namerane maximum

"Rozbeh demandu pomaly / throttle sleduje az po sekundach"
  -> ACCEL_MAX stale 0.0675 -> nastav 0.30 (novy vyznam = a0)
  -> PID I-lag pri rozbehu -> ladenie FF->P->I, nie krivka

"Slabe/agresivne brzdenie dopredu"
  -> VEC_BRK_ASYM plati aj pre linear brake -> C2

"Po zmene dopytu 0 -> plna rotacia je oneskorenie"
  -> ACC_MAX < 45 -> P0.1
  -> pivot coast bezi po flip -> normalne do VEC_TRN_MS

"Oscilacia rotacie bez zasahu brzdy"
  -> najprv B1/B2 overit plateau; potom VEC_YAW_EXP -0.2
  -> serva slew pomalsia nez rampa -> DEC_MAX zniz na 30

"Mrtvy throttle > ~1 s po akomkolvek manevri"
  -> VEC_TRN_MS > 3000 alebo < 0? -> P0.2
  -> DEADBAND prilis vysoky -> D1 -0.01
  -> disarm/failsafe/motor limit -> mimo tento guide (PC log)

"Drift odhad sa adaptuje pomaly (> ~30 s)"
  -> normalne ~16-24 s; ak dlhsie -> E4 DRIFT_EST_YR +5,
     E5 ALPHA +0.05

"Loiter odhad klesa k nule hoci drift existuje"
  -> zero-decay: ak loď drzi bez velkeho I, je to spravne.
     Ak odhad zanika zle -> LOIT_I_MIN -0.01 (E3)

========================================================================
SEKCIA 5 — CO TENTO GUIDE NEVYRIESI (last resort = PC log)
========================================================================
Na vode neviditelne bez logu — pred ukoncenim testu vycerpaj vsetky
parametre vyssie a zapíš symptom (screenshot Full Parameter List):
- Interne allocator stavy: rot_brake latch, coast okno, fold flag,
  vec_mag, throttle_norm znamienko — v MP labely neexistuju.
- EEPROM kolizia parametrov, neinicializovany stav, wind-up I-termu
  pocas zamrznutia — len v logu.
- "Drift sa nevzorkuje" po E3-E4 -> metoda gated interne -> PC log.
Ak dojdeš sem: ukonci ladenie, zaznamenaj presny symptom + parameter
